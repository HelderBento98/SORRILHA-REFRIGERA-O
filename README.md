# Sorrilha Refrigeração: site

Site de uma página da Sorrilha Refrigeração (Gabriel Sorrilha), Sertãozinho - SP.
Só HTML e CSS, sem JavaScript e sem etapa de build. Publicado pelo GitHub Pages.

## Estrutura
- `index.html`: conteúdo do site
- `assets/css/style.css`: visual (cores da marca no topo do arquivo)
- `assets/img/`: logo, símbolo, favicon e imagem de compartilhamento
- `assets/fonts/`: fonte Outfit (OFL)
- `assets/icons/`: ícones Phosphor (MIT), só os usados no site

## Trocar o WhatsApp
Em `index.html`, use "localizar e substituir" trocando `5575999062183` pelo novo número
(55 + DDD + número) e `(75) 99906-2183` pelo número exibido.

## Publicar
Settings → Pages → Source: *Deploy from a branch* → Branch `main` / `(root)`.
